1. Programming & Natural Languages

Codebase & Runtime

  • • Core Language: Modern JavaScript (ES Modules: import/export).
  • • Backend Runtime: Node.js (v18.x, v20.x, v22+ LTS).
  • • Frontend Engine: Vanilla ES6+ SPA (Zero heavy React/Vue dependencies for ultra-fast load time).
  • • Markup & Styles: HTML5, Tailwind CSS, Custom SVG Charting.

Supported Natural Languages

  • • Arabic (Gulf / Saudi Dialect): Native fluency (أبشر، يا هلا، سم).
  • • Arabic (Egyptian Dialect): Conversational fluency (أوامرك، تحت أمرك).
  • • Franco-Arab (Arabizi): Understands romanized Arabic chat.
  • • English: Professional US / UK bilingual support.

3. Server Sizing & Hardware Requirements

Standard / Single Business Tier

Up to 5,000 msgs/day

Ideal for car dealerships, certified pre-owned showrooms, auto agencies, and vehicle distributors.

  • vCPU 1 vCPU (2.0 GHz+)
  • RAM (Memory) 512 MB – 1 GB RAM
  • Disk Space 10 GB SSD / NVMe
  • Estimated Cost $4 – $6 / month (Hetzner, DO, AWS Lightsail)

High-Volume Enterprise Tier

50,000+ msgs/day

Ideal for franchise chains, high-traffic retail, and large customer care centers.

  • vCPU 2 – 4 vCPUs
  • RAM (Memory) 2 GB – 4 GB RAM
  • Disk Space 25 – 50 GB NVMe SSD
  • Estimated Cost $12 – $24 / month

4. Operating System & Network Prerequisites

Supported Operating Systems

Ubuntu 22.04 LTS, Debian 12, Alpine Linux, or Windows Server 2019/2022.

HTTPS & SSL Certificate

Mandatory for Meta Webhook verification (via free Let's Encrypt, Cloudflare, or Nginx).

Process Management

Runs 24/7 via PM2 (pm2 start server.js), Systemd service, or Docker container.

Designed for zero runtime lock-in and minimal infrastructure overhead.
